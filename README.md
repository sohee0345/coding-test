# 💻 Coding Test

**Python 문제 해결 능력과 코딩테스트 기초 실력을 기르기 위한 저장소**이다.

문제를 직접 풀고 풀이 과정을 복습하며,
틀렸거나 헷갈렸던 문제는 다시 풀어보면서 학습 내용을 기록한다.

---

## 📂 Structure

```text
coding-test/
├── programmers/
│   ├── pcce/
│   ├── level0/
│   ├── level1/
│   └── ...
└── README.md
```

프로그래머스 문제를 유형이나 난이도에 따라 분류하여 정리한다.

학습이 진행됨에 따라 필요한 폴더와 문제를 계속 추가한다.

---

## 📝 Solution Format

각 문제 파일에는 다음 내용을 중심으로 기록한다.

```text
문제명
난이도
풀이 날짜

문제 핵심
내 풀이
다른 풀이
틀린 이유 / 헷갈린 점
배운 점
```

문제에 따라 필요하지 않은 항목은 생략한다.

---

## 🎯 Goal

* Python 기본 문법을 문제풀이를 통해 익힌다.
* 문제를 보고 필요한 로직을 직접 생각하는 연습을 한다.
* 조건문, 반복문, 함수, 자료구조 사용에 익숙해진다.
* 다양한 유형의 문제를 풀며 문제 해결 능력을 향상시킨다.
* 틀린 문제와 어려웠던 문제를 다시 풀며 부족한 부분을 확인한다.
* 정답만 맞히는 것이 아니라 풀이 과정을 설명할 수 있도록 연습한다.

---

## 📌 Problems

현재 프로그래머스 문제를 중심으로 풀이한다.

`PCCE` · `Lv.0` · `Lv.1` · `...`

학습이 진행됨에 따라 더 다양한 난이도와 문제 유형에 도전한다.

---

## ✅ Study Rule

* 먼저 스스로 문제를 충분히 고민한다.
* 풀이 후 더 간단하거나 효율적인 방법이 있는지 확인한다.
* 틀린 문제는 틀린 이유를 확인하고 기록한다.
* 이해하지 못한 코드는 그대로 사용하지 않는다.
* 다시 풀어볼 필요가 있는 문제는 표시하여 복습한다.

---

> 정답을 맞히는 것보다 문제를 이해하고 스스로 풀이 과정을 만들어가는 것을 목표로 한다.
